This returns a list with a summary of the pairwise distances \(within_ strata and Nei's dA and pairwise distances _\)between strata.

For standard measures of population structure (e.g., Fst, PHIst, Jost’s D, etc.), there are two main functions. The first, overallTest() computes the test statistic and permutation p-value for the global null hypotheses that all individuals have been drawn at random from a single population and stratification was random with respect to individual genotypes. The test will compute all statistics and their respective permutation p-values (if nrep > 0). The statistics computed will be different depending on if the gtypes object provided is haploid or diploid.

Here is an example for haploid sequence data:

ovl <- overallTest(dloop.g)
ovl
$strata.freq

       Coastal Offshore.North Offshore.South 
            68             40             18 

$result
      estimate p.val
CHIsq   189.67 0.001
Fst       0.13 0.001
PHIst     0.29 0.001

The result is a list with the sample size (\(strata.freq_) of each stratum, and a matrix with the values of the test statistic and p-value (_\)result).

This produces a list where each element is a unique pair of strata. The results for each pair of strata are formatted the same way as the single result from overallTest().

Here, there is one row for each pairwise test with a formatted label column that provides the strata and sample size and then columns following the individual strata, sample sizes, test statistics, and their p-values.

For a given statistic, one use pairwiseMatrix() to produce a summary matrix that gives the test statistic in the lower left and p-value in the upper right:

pairwiseMatrix(pws, stat = 'Fst')
               Coastal Offshore.North Offshore.South
Coastal             NA         0.0010          0.001
Offshore.North    0.15             NA          0.543
Offshore.South    0.16        -0.0027             NA
